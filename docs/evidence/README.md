# Evidence index

## Important revision note

The PNG captures and text records in this folder are from earlier revisions of the website. Some show the now-removed interactive planner; some record the former Netlify deployment. They are retained as a historical archive and are not evidence that the current static release has been validated or deployed.

The current release checks are summarized in [testing.md](../../testing.md). Current manual checks still needed are listed in [the manual test sheet](../manual-test-sheet.md).
