# Project evidence

## A note before you browse

Most screenshots and text records here were made before I changed the project to a static site. Some show the planner I removed, and some show an earlier Netlify version. I kept them as a record of the project, but they do not prove that the current release passed the same checks or that the current live site has been fully reviewed.

I have summarized the checks for the current release in [testing.md](../../testing.md). The manual checks I still need to do are in [the test sheet](../manual-test-sheet.md).
